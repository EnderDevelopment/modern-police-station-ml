# Modern Police Station MLO

This FiveM resource adds a modern police station MLO (Map Location Object) with dedicated SWAT and Internal Affairs Agency (IAA) sections. The resource includes scripts for teleporting players to the main station, SWAT section, and IAA section, as well as blips for easy navigation. The MLO files are included for seamless integration into your FiveM server.

## Install

1. Download the resource from the GitHub repository.
2. Extract the files into your FiveM server's `resources` directory.
3. Add `start modern_police_station` to your server.cfg file.

## Use

1. Connect to your FiveM server.
2. Use the following commands to teleport to different sections:
   - `/gotops` to teleport to the main police station.
   - `/gotoswat` to teleport to the SWAT section.
   - `/gotoiaa` to teleport to the IAA section.
